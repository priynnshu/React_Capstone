# 🌍 Smart Travel Planner

## 📌 Project Overview

Smart Travel Planner is a web-based application built using React that helps users plan their trips efficiently. The application allows users to search for a city and get real-time weather updates, explore popular tourist attractions, and create a personalized day-wise itinerary.


---

## 🚀 Features

### 🔍 City Search

* Users can search for any city
* Fetches real-time data using APIs

### 🌦️ Weather Information

* Displays current weather conditions
* Shows temperature, humidity

### 📍 Tourist Attractions

* Displays popular places to visit

### 📅 Itinerary Builder

* Create day-wise travel plans
* Add/remove places
* Organize activities per day


### 📊 Travel Summary

* Overview of total days and activities

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Styling:** CSS
* **APIs Used:**

  * OpenWeather API (Weather Data)
  * Places API (Tourist Attractions)
  * (These APIs can change acc. to how these will work and what all we will need)

---

## ⚙️ How It Works

1. User enters a city name
2. App fetches weather and places using APIs
3. User selects places and adds them to itinerary
4. Data is stored locally for persistence
